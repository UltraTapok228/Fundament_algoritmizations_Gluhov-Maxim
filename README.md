# algo-portfolio · ОП.04 «Основы алгоритмизации и программирования»

Ваш репозиторий на всю дисциплину: решения задач, тесты к ним и заметки о том,
сколько решение стоит по времени и памяти. К концу курса это и есть портфолио,
которое можно показать на собеседовании.

## Сделать репозиторий своим

Нажмите **Use this template → Create a new repository**, назовите
`algo-portfolio` и выберите видимость. У вас появится собственный репозиторий
с чистой историей, он остаётся у вас и после дисциплины. Форк для этого не
подходит: он остаётся привязан к исходному репозиторию.

## Установка

Нужны **Python 3.12** и **git**. На Windows при установке Python отметьте
галочку *Add Python to PATH*.

```bash
git clone <адрес вашего репозитория> algo-portfolio
cd algo-portfolio
```

Дальше команды различаются:

| Шаг | macOS / Linux | Windows (PowerShell) |
|---|---|---|
| создать окружение | `python3 -m venv .venv` | `py -m venv .venv` |
| активировать | `source .venv/bin/activate` | `.venv\Scripts\Activate.ps1` |
| поставить pytest | `pip install -r requirements.txt` | то же |
| проверить | `pytest --version` | то же |

Последняя команда должна напечатать версию pytest — значит всё готово.
Активировать окружение нужно перед каждой работой: в начале строки
появится `(.venv)`.

*Если PowerShell не даёт запустить `Activate.ps1`, один раз выполните
`Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`. В cmd активация —
`.venv\Scripts\activate.bat`.*

## Структура

```
lesson_01/      занятие 1: алгоритмы вокруг нас, инвариант
lesson_02/      занятие 3: сложность и O-нотация — три бланка домашнего задания
```

На каждое занятие с домашней работой — своя папка; занятие 2 идёт без неё,
поэтому нумерация папок и нумерация занятий расходятся. Задачу и заготовку
решения я выдаю на паре, вы кладёте их в ту же папку, рядом с бланками.
Папку для следующего занятия делаете копией предыдущей:
`cp -r lesson_02 lesson_03` (на Windows — `Copy-Item -Recurse lesson_02 lesson_03`).

Что сдавать и что проверяется — в `README.md` внутри папки занятия. Там же
чек-лист, который проходят перед Pull Request.

## Как сдавать

```bash
git switch -c hw-02          # ветка на задание, номер по папке
pytest lesson_02             # тесты своей папки
git add lesson_02
git commit -m "hw-02: разметка сложности, ограничения, приёмка"
git push -u origin hw-02
```

Дальше на GitHub открываете **Pull Request** в свою `main` и коротко пишете:
что за задача, какой подход выбрали, сколько он стоит по времени и памяти,
какие тесты добавили. Срок — до начала следующего занятия.

Всё то же самое можно делать мышкой в VS Code, без терминала. Разбор
со скриншотами: [коротко](docs/git/README.md) — основные операции
с размеченными кадрами, [подробно](docs/git/FULL.md) — каждый шаг,
включая типичные ошибки.

## Правила

- На тренировке ИИ можно **после собственной попытки**: review, дополнительные
  тесты, оформление готовых мыслей в `.md`. Ответ проверяете запуском.
- На диагностике, mock-интервью, контестах и экзамене ИИ, поиск и
  автодополнение закрыты.
- Тесты должны запускаться у другого человека после `git clone`.
