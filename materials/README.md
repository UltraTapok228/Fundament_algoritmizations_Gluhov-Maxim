# Материалы занятий

Файлы, которые раздавались на занятиях: программы, заготовки решений,
тесты, бланки. Одна папка — одно занятие или модуль книги. Конспекты
лежат в папке [`lectures`](../lectures/README.md).

Чтобы поработать с набором, скопируйте его папку в папку своего задания
или откройте прямо здесь: тесты запускаются из папки набора, например
`cd materials/modul-08-dva-ukazatelya/lesson_08 && pytest tests.py -q`.
